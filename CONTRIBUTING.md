# Contributing

Open an Issue with a minimal synthetic fixture, desired behavior, suspected false positive/negative, and primary-source documentation. Add tests for positive and negative patterns before changing a rule. Never commit real credentials or confidential repository contents. Fork/branch, run `python -m unittest discover -s tests -v`, and open a PR referencing the relevant rule. Be respectful and include a reproducible command; a passing fixture is not proof of full language/dialect coverage.
